# Evergreen docs site

The mdBook under `docs/` is now published at
https://evergreen-soroban.netlify.app, so the introduction, getting started,
architecture, state archival and roadmap pages can be read without cloning the
repository. The README links to it, and `evergreen-core`'s `homepage` points
to it, as its manifest comment asked once the book was deployed.

`docs/netlify.toml` builds the book with mdBook 0.5.4. The Netlify build image
has no mdBook, so the build downloads that release and checks its SHA-256
before running it. Builds are skipped when nothing under `docs/` changed. The
built `docs/book/` folder is ignored by Git.

No crate behaviour changed.
