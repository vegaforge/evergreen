# evergreen-core on crates.io

`evergreen-core` 0.1.0 was published to
[crates.io](https://crates.io/crates/evergreen-core) on 2026-11-07, from commit
09209b6 on main. A contract can now depend on it with
`evergreen-core = "0.1"` instead of a Git dependency.

The installation page, the API reference (now pointing at docs.rs), the roadmap
and the changelog say so, and the README shows crates.io and docs.rs badges.
The other crates are still interface only and are not published.

No code changed.
